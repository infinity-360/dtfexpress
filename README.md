# Estampas DTF Express — site

Site estático: home, foto da fachada, orientações de aplicação e montador DTF online (Têxtil 58 cm e UV 29 cm).

- `index.html` — página inicial (foto da fachada em `assets/fachada.jpg`)
- `montador.html` — montador DTF: upload, tamanho/quantidade, montagem automática e PNG 300 DPI
- `js/config.js` — WhatsApp, preços por metro, larguras de filme, margens e DPI
